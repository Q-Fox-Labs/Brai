# Авторизация

ID: `auth`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Отправляет код входа по почте, проверяет его, создаёт сессию и завершает её.

## Использование

Используй форму входа Web. После неопределённого результата входа сначала проверь текущую сессию; повторная отправка кода — отдельное действие.

## Ограничения и связи

Принятие письма провайдером не гарантирует доставку в ящик. Доступность зависит от почтовой конфигурации экземпляра.

Связанные компоненты: [web](web.md).
