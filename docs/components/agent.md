# Интеграция Codex

ID: `agent`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Соединяет Brai с нативными чатами Codex и предоставляет независимый publisher файлов.

## Использование

Работай с чатами через интерфейс Brai. Для готового файла используй publish_file, а для чтения опубликованного — fetch_file в подключённом publisher.

## Ограничения и связи

Brai не подменяет владельца выполнения Codex. Неизвестная отправка не повторяется автоматически. Publisher может работать независимо от основного Agent.

Связанные компоненты: [artifacts](artifacts.md), [web](web.md).
