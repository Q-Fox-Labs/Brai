# Компоненты Brai

Сначала выбери возможность в индексе, затем прочитай её карточку. Карточка объясняет обычное использование и ведёт к техническому README владельца. Контракты, схемы и код не копируются в справку.

Приложение Web предоставляет интерфейс, сервисы владеют своими данными и операциями, адаптеры соединяют их с внешними программами. Основные границы — явные API и сообщения; транспорт и хранилище описаны у владельца. Состав и зависимости поставки определяются существующими `component.json`, а не этим индексом.

| [auth](auth.md) | Вход по почтовому коду и сессии |
| [game-core](game-core.md) | Задачи, цели, квесты и их выполнение |
| [goals](goals.md) | Личные цели, фокус, ресурсы и реальные результаты |

## Выведенные и отдельные материалы

- [codeworks-agent](codeworks-agent.md) — retired; прежний контроллер не поставляется.
- [Dialogues](../../services/dialogues/README.md) — проект контракта без самостоятельного действующего компонента.
- [Instaloader](../environment/instaloader.md) — внешний рецепт, относится к окружению.

Для нового действующего собственного компонента обязательны карточка с именем его ID и технический README рядом с реализацией. В индексе не создаётся отдельная идентичность компонента. Возврат к [главному документу](../README.md).

Запись перехода Codeworks: [выведенный компонент](elements.md). Она не объявляет действующий сервис.
