# Рабочие области и поставки

ID: `codeworks`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Подготавливает рабочие области, сохраняет изменения и координирует GitHub, CI, выпуск и очистку.

## Использование

Через CLI или подключённый API запрашивай prepare/status/sync/release/cleanup. После изменяющего запроса сохрани ID операции и проверяй её состояние.

## Ограничения и связи

Сервис не запускает агента и не расширяет его права. Успешная подготовка или CI не подтверждает установку; правила работы конкретной команды задаются отдельно.

Внешние зависимости описаны в [окружении](../environment/README.md).
