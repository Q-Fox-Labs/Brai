# Прежний сервис Codeworks

ID: `codeworks`. Статус: **retired**. Компонент исключён из состава DEV; исходники сохранены для истории и переноса незавершённой работы. Отключение работающих служб выполняется отдельно.

[Дескриптор](../../services/codeworks/component.json) сохраняет идентичность и прежнюю службу. [Техническое описание](../../services/codeworks/README.md) и контракт описывают прежнее поведение.
