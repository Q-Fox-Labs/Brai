# Рабочие области и поставки

ID: `codeworks`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Подготавливает рабочие области, сохраняет изменения и координирует GitHub, CI, выпуск и очистку. DEV-выпуск также подтверждает обновление основной локальной копии и готовность зависимостей для следующей задачи; конфликт с незавершённой работой сохраняет причину ожидания.

При включённой настройке автоматически публикует веб рабочей ветки до слияния. Превью использует общие сервисы и данные DEV; изменение данных через сайт сохраняется в DEV. Статус показывает адрес и опубликованный коммит, очередь и срок аренды. Серверные изменения смешанной ветки в превью не устанавливаются.

Временные ошибки GitHub, публикации CI-каталога и проверки архива сохраняют
работу для повтора. Оператор может продолжить проверенную очистку, восстановить
незавершённый workflow или завершить проверку после успешной установки.
Такое восстановление сохраняет прежние доказательства и не разрешает
повторять установку либо удалять неподтверждённые ресурсы.

## Использование

Для новой задачи начни с поддерживаемой файловой записи: подключённый hook подготовит область и направит запись в неё. Через status найди и продолжи существующую область; публичный prepare не создаёт новую заранее. После изменяющего запроса сохрани ID операции и проверяй её состояние. sync публикует рабочую ветку, release выполняет принятый выпуск, а закрытие и очистка учитываются отдельно.

Связь рабочей области с PR сохраняется в Codeworks. Заголовок и описание PR
можно редактировать; проверки репозитория, веток и коммита сохраняются.

## Ограничения и связи

Сервис не запускает агента и не расширяет его права. Успешная подготовка или CI не подтверждает установку; неизвестный исход записи удерживает очистку до сверки; правила работы конкретной команды задаются отдельно.

Внешние зависимости описаны в [окружении](../environment/README.md).

## Технические подробности

[README владельца](../../services/codeworks/README.md) — устройство, конфигурация, интерфейсы и проверки. Форматы и гарантии определяются документами владельца.

[Индекс компонентов](README.md).

Для новой самостоятельной задачи можно задать разовый ключ
`-c codeworks.workspace=creator-development` в штатной первой команде
`git apply` из основного репозитория. Составное чтение чужого дерева не
выбирает область; проверка чужого дерева сохраняет защиту записи, но не
меняет текущую задачу. Продолжение использует последний выбранный ключ.
