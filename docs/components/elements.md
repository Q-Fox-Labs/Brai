# Элементы работы

ID: `elements`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Хранит задачи, цели, квесты, их планы, операции, ресурсы и решения пользователя.

## Использование

Поручи пользовательскому агенту запланировать или продолжить дело. Агент сначала сопоставляет поручение с существующей картой, затем получает актуальный пакет планирования. Решение по плану принимает пользователь.

## Ограничения и связи

Прочтение неполной карты не доказывает отсутствие задач. Агент не подтверждает пользовательские действия за человека.

Связанные компоненты: [hermes](hermes.md), [history](history.md).
