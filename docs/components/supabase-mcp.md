# Доступ к данным через MCP

ID: `supabase-mcp`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Предоставляет ограниченную границу MCP для работы с разрешёнными данными Supabase.

## Использование

Используй только инструменты подключённого MCP с выданными правами. Перед изменением изучи описание операции и доступную область.

## Ограничения и связи

Наличие сервиса не означает произвольный административный SQL-доступ. Подключения и права задаёт оператор.

Внешние зависимости описаны в [окружении](../environment/README.md).
