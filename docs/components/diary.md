# Дневник

ID: `diary`. Компонент подготовлен для DEV; наличие исходников не подтверждает установку.

## Назначение и возможности

Принимает аудиодневник через браузер, сохраняет оригинал в Artifacts, получает
расшифровку через Transcription и передаёт её Luna для исправления текста и
определения даты события. Записи и этапы обработки хранятся в собственной базе.
Агент может читать записи и сохранять точный текст через MCP.

## Использование

Открой раздел «Дневник», выбери аудиофайл и дождись загрузки. После приёма файла
сервер продолжит обработку независимо от вкладки. Открой запись, чтобы прочитать
исправленный текст, исходную расшифровку и свидетельство даты или прослушать оригинал.

Если передача оборвалась, повторно выбери тот же файл. Он отправится целиком;
продолжения с места обрыва нет. Повтор уже принятого файла не создаёт дубль.

## Ограничения и связи

Неизвестная дата остаётся неизвестной. Дата загрузки не подставляется вместо даты
события. Сбой с неизвестным исходом вызова Luna останавливает обработку для проверки,
без автоматического повторного вызова модели. Редактирование, удаление и публичные
ссылки этой версией не предоставляются.

Каждый пользователь получает только свои записи. Нужны [auth](auth.md),
[artifacts](artifacts.md), [transcription](transcription.md) и настроенный доступ
к Luna. [Web](web.md) показывает записи, но не владеет ими.
