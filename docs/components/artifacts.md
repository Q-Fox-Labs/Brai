# Файлы и результаты

ID: `artifacts`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Хранит файлы, метаданные, связи, входящие вложения и привязки результатов.

## Использование

Для выдачи готового файла используй подключённый publisher: публикация возвращает идентификатор и дескриптор. Для дальнейшей работы получай файл по идентификатору.

## Ограничения и связи

Успех требует готовности файла и проверки владельца. Существующий ID или локальный путь сами по себе не дают права доступа; опубликованные байты неизменяемы.

Связанные компоненты: [agent](agent.md), [hermes](hermes.md), [web](web.md).
