# Приём событий

Приём регистрирует события через общий JetStream вход и выбирает сквозную обработку
Temporal либо надёжную передачу получателю без Temporal. Сообщение пользователя
и каждый содержательный ответ Hermes обрабатываются отдельно со связями причины
и беседы. Входящие сохраняют сообщения, Понимание и память — свои результаты.

Первый компонент самостоятельный. Отсутствующие соседи доступны тестовому стенду;
подключение рабочего Telegram выполняется отдельно. Служебные сообщения Hermes
этим компонентом не переключаются.
