# Расшифровка аудио

ID: `transcription`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Принимает задания распознавания, выбирает разрешённый маршрут и предоставляет состояние и результат.

## Использование

Передай готовое аудиовложение через доступный инструмент, сохрани ID запроса, проверяй состояние и получи доступный результат. Голосовые сообщения агента используют этот же сервис.

## Ограничения и связи

Результат имеет ограниченное время доступности. Таймаут не означает отмену вычисления; после неизвестного исхода сначала проверь запрос.

Связанные компоненты: [local-ai](local-ai.md), [artifacts](artifacts.md), [hermes](hermes.md).
