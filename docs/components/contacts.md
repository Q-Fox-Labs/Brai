# Контакты

Контакты сопоставляют отправителей по внешнему аккаунту и хранят актуальный профиль.
Один Telegram User ID через разных ботов владельца соответствует одному контакту;
разные владельцы разделены. Имя, username и фото не объединяют разные аккаунты.

На каждое поступление сохраняется неизменяемый снимок наблюдения. Новый профиль
не переписывает старые сообщения. Недоступное фото не блокирует сообщение,
автор ответа Hermes остаётся агентом.

Самостоятельный сервис и связка с Приёмом находятся в невыпущенной области.
Наличие исходников не означает включение в экземпляре или переключение Telegram.
