# Контакты

Статус: согласованный контракт; сервис ещё не реализован и не включён в экземпляр.

Контакты сопоставляют отправителей по внешнему аккаунту и хранят актуальный профиль.
Один Telegram User ID через разных ботов одного владельца соответствует одному
контакту. У разных владельцев записи разделены. Имя, username и фото не объединяют
разные аккаунты.

Для каждого поступления сохраняется неизменяемый снимок сведений отправителя.
Изменение актуального профиля не меняет прежние сообщения. Недоступность фотографии
не останавливает обработку сообщения. Ответ агента сохраняет авторство агента.
