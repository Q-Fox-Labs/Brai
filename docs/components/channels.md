# Каналы

Каналы хранят подключения, адреса диалогов и топиков, версии настроек и правила. Приём получает исторический снимок через resolve, доставка отдельно проверяет текущее право отправки. Первый профиль — Telegram; сам сервис не подключается к Bot API.

Компонент создаётся для самостоятельной приёмки и тестовой связки с Приёмом. Наличие исходников не подтверждает включение в экземпляре. Настройка рабочего Telegram выполняется только в принятом общем комплекте.
