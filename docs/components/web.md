# Веб-интерфейс

ID: `web`. Описывает компонент в исходниках; его включённость проверяется в своём экземпляре.

## Назначение и возможности

Открывает возможности Brai в браузере: вход, интервалы времени, элементы работы, чаты и результаты.

## Использование

Открой адрес своего экземпляра и войди по почтовому коду. Выбери нужный раздел интерфейса; доступность разделов зависит от подключённых сервисов.

## Ограничения и связи

Интерфейс не владеет данными соседних сервисов и не заменяет их API. После несовместимого обновления может потребоваться обновить вкладку.

Связанные компоненты: [auth](auth.md), [timer](timer.md), [elements](elements.md), [agent](agent.md), [artifacts](artifacts.md).
