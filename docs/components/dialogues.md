# Диалоги

ID: dialogues. Среда: DEV. Независимое прямое хранилище публичной переписки и подготовленных агентом саммари.

Агент сохраняет реальные inputs и finals через MCP. На каждом ходе новый pull возвращает полную подборку последних 50 отдельных сообщений из всех разрешённых бесед, включая неотвеченные inputs. При старте дополнительно приходят свёртки всех бесед, после подтверждения — только их обновления. Все страницы нужно прочитать и подтвердить ACK. Точные ID сохраняют группировку и происхождение. Прежний context_get с парами остаётся совместимым.

Оригинал остаётся доступным для дочитывания. При отсутствии саммари используется исходный текст в пределах размера ответа. Неполное покрытие и фрагмент оригинала обозначаются явно. Отдельного ограничения длины саммари нет: большую свёртку агент получает полностью частями и собирает по версии, Unicode offsets и контрольной сумме. Размер страницы ограничивает передачу, а не смысл или общий размер свёртки.

Запись по-прежнему зависит от действий агента. Фоновый worker сворачивает беседу после десяти новых сообщений либо после шести часов тишины при непустом хвосте. Он использует точную Luna через существующий App Server, сохраняет оригиналы и публикует версию с явным покрытием. Автоматического захвата, интерфейса и интеграции с информационным ядром нет. Подключение конкретного экземпляра подтверждается отдельно.

Техническое устройство и ограничения — в [README](../../services/dialogues/README.md) и [контракте](../../services/dialogues/CONTRACT.md). Прежнее архивное хранилище сохраняется отдельно от live.
