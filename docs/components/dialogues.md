# Диалоги

ID: dialogues. Среда: DEV. Независимое прямое хранилище публичной переписки и подготовленных агентом саммари.

Агент сохраняет оригиналы через MCP, отдельно добавляет версии саммари и получает последние 50 завершённых пар обращения/итога из всех своих бесед. Продолжение читается по непрозрачному курсору. Контекст сгруппирован по точным ID бесед и ходов; промежуточные ответы сохраняются, но не занимают места этих пар.

Оригинал остаётся доступным для дочитывания. При отсутствии саммари используется исходный текст в пределах размера ответа. Неполное покрытие и усечение обозначаются явно.

Это ручной MCP-MVP: полнота зависит от действий агента. Автоматического захвата, моделей для свёртки, расписаний, интерфейса и интеграции с информационным ядром нет. Подключение конкретного экземпляра подтверждается отдельно.

Техническое устройство и ограничения — в [README](../../services/dialogues/README.md) и [контракте](../../services/dialogues/CONTRACT.md). Прежнее архивное хранилище сохраняется отдельно от live.
