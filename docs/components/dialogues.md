# Диалоги

ID: dialogues. Среда: DEV. Независимое прямое хранилище публичной переписки и подготовленных агентом саммари.

Агент сохраняет реальные входы и финалы через единый MCP-обмен. Ход объединяет дополнения и ожидаемые результаты; перед отправкой ответа агент согласует финал с сервисом. На старте контекст содержит свёртки бесед, несвёрнутые сообщения и окно последних 50 отдельных сообщений без повторов. После подтверждения приходят новые изменения; страницы подтверждаются отдельным ACK.

Для сообщения длиннее 100 Unicode-символов обязательно саммари. История беседы возвращается страницами саммари, а оригинал запрашивается отдельно по ID сообщения. Длинное саммари передаётся полностью частями с контрольной суммой.

Описание MCP содержит примеры ввода и финала. При неверном запросе сервис указывает поле и ожидаемый формат; агент исправляет аргументы и сразу повторяет с новым ID запроса, если запись не выполнялась. Отказы журналируются без текста переписки. При неизвестном исходе сначала проверяется состояние.

Запись по-прежнему зависит от действий агента. Фоновый worker сворачивает беседу после десяти новых сообщений либо после шести часов тишины при непустом хвосте. Он использует точную Luna через существующий App Server, сохраняет оригиналы и публикует версию с явным покрытием. Временные запросы саммаризации не создают сохраняемых чатов Codex; после сбоя незавершённый фрагмент можно запросить заново. Автоматического захвата, интерфейса и интеграции с информационным ядром нет. Подключение конкретного экземпляра подтверждается отдельно.

Персональное подключение использует отдельный обработчик и логин базы для каждого аккаунта. RLS ограничивает все пользовательские таблицы; Auth проверяется до операции и выдачи. Подготовка нового пользователя через приглашение выполняется операторским lifecycle автоматически. Первый владелец сохраняет существующую историю и подключение Codex. Применение к конкретному экземпляру требует отдельной приёмки и проверки.
