# Средства исполнения

Node.js исполняет приложения и адаптеры; Python и native runtime обслуживают отдельные инструменты и модели; контейнеры упаковывают поставки.

## Подключение, совместимость и доступность

Точные требования принадлежат дескрипторам и lock-файлам. Модельные runtime управляются Local AI; отдельный процесс с весами не считается установленной моделью продукта.

Адреса и полномочия передаются конфигурацией экземпляра; общая справка не содержит настроек конкретного сервера.

[Техническое описание или рецепт](../../package.json). [Связанная граница Brai](../../services/local-ai/README.md).

[Индекс окружения](README.md).

Требования к зависимостям и запуску указаны в технических описаниях компонентов. Операторские плейбуки находятся в отдельном репозитории Admin; пользовательский установщик будет отдельным решением.
