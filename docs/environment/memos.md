# MemOS

Внешний движок памяти пользовательского агента. Brai предоставляет адаптер embeddings и bridge обработки текста.

## Подключение, совместимость и доступность

Подключение и хранение памяти принадлежат экземпляру MemOS. Проверяй его API и адаптеры отдельно; инструкции поведения и переписка не заменяют память и не копируются в неё автоматически.

Адреса и полномочия передаются конфигурацией экземпляра; общая справка не содержит настроек конкретного сервера.
