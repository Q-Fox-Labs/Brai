# Окружение Brai

Здесь описаны готовые внешние программы, существенные для работы Brai. Собственные сервисы и адаптеры перечислены в [компонентах](../components/README.md). Установка зависит от конфигурации экземпляра; наличие рецепта не подтверждает работающий процесс.

| Программа | Назначение |
| --- | --- |
| [NATS](nats.md) | Запросы, события и долговечные каналы |
| [Supabase и PostgreSQL](supabase.md) | Внешняя платформа данных и отдельные БД сервисов |
| [Temporal](temporal.md) | Выполнение долговременных процессов |
| [Hermes](hermes.md) | Внешний движок пользовательского агента |
| [MemOS](memos.md) | Внешний движок памяти |
| [Codex](codex.md) | Внешний агент и его нативные чаты |
| [LiteLLM](litellm.md) | Внешний совместимый proxy поставщиков моделей |
| [Caddy](caddy.md) | Внешний HTTP reverse proxy и доставка файлов |
| [Instaloader](instaloader.md) | Внешняя программа получения материалов Instagram |
| [Средства исполнения](runtime.md) | Node.js, Python, контейнеры и модельные runtime |

Документ программы объясняет её роль, потребителей, совместимость и проверку доступности, затем ссылается на технический рецепт или адаптер. Адреса, секреты, установленные версии и инструкции управления конкретными серверами задаёт оператор вне публичной документации.

[Общие рецепты зависимостей](../../dependencies/README.md) и [средства поставки](../../deploy/README.md). Возврат к [главному документу](../README.md).
