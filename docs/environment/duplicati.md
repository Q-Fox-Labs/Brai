# Duplicati

Duplicati хранит резервные копии файлов и подготовленных дампов БД, в том числе
на Google Drive. Клиентский установщик готовит фоновую службу без веб-интерфейса;
управление выполняется через команды. Общую реализацию использует и Admin.

Подключение Google Drive, выбор источников, расписание и шифрование архивов
настраиваются отдельно. Пользовательский профиль Hermes следует включать
целиком с согласованными исключениями: одной папки `usercustom` недостаточно
для восстановления состояния агента. Работающие БД требуют согласованных дампов.
Установка сама не создаёт ни заданий, ни дампов.
