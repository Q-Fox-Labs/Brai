# Temporal

Внешняя среда долговременных процессов, используемая средствами выполнения Brai.

## Подключение, совместимость и доступность

Сервер, namespace и схема задаются конфигурацией. Проверяй подключение клиента и доступность нужного worker отдельно; наличие SDK не означает работающий сервер.

Адреса и полномочия передаются конфигурацией экземпляра; общая справка не содержит настроек конкретного сервера.
