# Пользовательский агент

Пользовательский агент помогает пользоваться Brai: ведёт разговор, работает с задачами и файлами, обращается к доступным сервисам. Это роль продукта; текущий движок — [Hermes](../environment/hermes.md), собственная интеграция — [адаптер Hermes](../components/hermes.md).

## Источники поведения

- [Базовые инструкции и навыки](instructions/README.md) поставляются с версией продукта.
- Правила планирования принадлежат [Elements](../components/elements.md) и поступают в текущем пакете планирования; их копии здесь не создаются.
- Личные дополнения располагаются в `usercustom/` этого раздела и исключены из Git. Это локальное место для дополнений, а не runtime-профиль Hermes. Память, переписка, секреты и код расширений хранятся отдельно.
- Подключения, выбор окружения и доступы предоставляет конфигурация экземпляра.

Агент пользуется только реально подключёнными инструментами и не обещает возможности отключённого сервиса. Пользовательские решения получает от пользователя; память и временные заметки не заменяют данные владельца задач.

Например, локальное дополнение usercustom/preferences.md может содержать предпочтение: «Отвечай кратко и указывай часовой пояс при обсуждении времени». Это пример пользовательского текста; его подключение выполняется явно средствами выбранного движка. Каталог не синхронизируется через Git и автоматически не загружается.

## Установка инструкций

[Техническое описание](../../services/hermes/README.md) связывает документацию с поставкой адаптера. Управляемые тексты берутся из принятой версии поставки; редактирование справки или локального checkout не меняет уже работающего агента. Установщик сохраняет личный текст вокруг известного управляемого блока; неизвестные изменения требуют разбора вместо перезаписи.

Возврат к [главному документу](../README.md).
