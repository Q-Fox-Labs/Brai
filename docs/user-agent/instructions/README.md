# Поставляемые инструкции агента

[Основное поведение](context.md) и [навык работы с задачами](skills/brai-task-workflows/SKILL.md) являются рабочими текстами. Они входят в версионируемую поставку адаптера Hermes. Изменение этих файлов требует проверки поведения перед применением.

Установщик добавляет контекст экземпляра отдельно; этот каталог не содержит адресов и параметров нашего сервера. Техническое описание загрузки — в [README Hermes](../../../services/hermes/README.md).

Навык использует [протокол планирования и результатов](skills/brai-task-workflows/references/planning-and-results.md). Сами правила планирования получает сервис-владелец, а не этот каталог.

Личные дополнения находятся вне этого каталога, в игнорируемом `../usercustom/`; они не включаются в manifest или поставку. Возврат к [описанию агента](../README.md).
