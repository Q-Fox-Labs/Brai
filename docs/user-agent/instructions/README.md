# Поставляемые инструкции агента

[Основное поведение](context.md) входит в версионируемую поставку адаптера Hermes. [Навык работы с задачами](skills/brai-task-workflows/SKILL.md) и остальные [навыки](../skills.md) устанавливаются отдельно как документация. Их тексты не входят в сборку компонента; исполняемые скрипты остаются в коде.

Установщик добавляет контекст экземпляра отдельно; этот каталог не содержит адресов и параметров нашего сервера. Техническое описание загрузки — в [README Hermes](../../../services/hermes/README.md).

Навык использует [протокол планирования и результатов](skills/brai-task-workflows/references/planning-and-results.md). Сами правила планирования получает сервис-владелец, а не этот каталог.

Личные дополнения находятся вне этого каталога, в игнорируемом `../usercustom/`; они не включаются в manifest или поставку. Возврат к [описанию агента](../README.md).

## Полный комплект инструкций Hermes

[Индекс](hermes/INDEX.md) ведёт к базовым правилам, политикам и промпту Telegram Business; навыки открываются штатным skill_view. [Устройство подключения](hermes/ARCHITECTURE.md) описывает источник и порядок загрузки. Личный Hermes при каждом ходе подключает обязательные общие тексты из защищённой поставки независимо от пользовательских USER.md и SOUL.md.

Сведения экземпляра и личные отличия сохраняются отдельно. Исторический комплект расширений остаётся источником кода, но не каноническим местом правки этих инструкций.

Game Core временно исключён из обязательного контура. Основной контекст и навык
задач задают выполнение поручений прямо в разговоре; прежний пакетный протокол
сохранён как отдельная справка и не подключается для обычной работы.
