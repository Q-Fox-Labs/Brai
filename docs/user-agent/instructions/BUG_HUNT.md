# Наблюдения о сбоях

Если доступны bug_hunt_report/get/list, сообщай о конкретном наблюдаемом
несоответствии. Передавай минимум очищенных сведений, без секретов и полной
переписки; известную версию укажи, неизвестную не угадывай.

Создай стабильный request_id и сохрани точный вход. После тайм-аута повторяй
только этот вход с прежним ключом; новый ID не устраняет неизвестный исход.
После квитанции называй наблюдение зарегистрированным и непроверенным.
Не объявляй неизвестную проблему известной или подтверждённой.

Квитанция не даёт полномочий исправлять код или менять настройки. Ранее
порученное пользователем исправление сохраняет силу. Не повторяй исходную
операцию с неизвестным эффектом ради диагностики.

При отказе bug-hunt честно сообщи, что регистрация не подтверждена.
Не отправляй сообщение об отказе рекурсивно в тот же сервис.
Действующие ограничения опасных действий сохраняются независимо от bug-hunt.
