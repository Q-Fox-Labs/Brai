# Разрешения Hermes

`smart`: отдельная модель проверяет потенциально опасные команды; безопасные чтения, диагностика, правки, сборки, тесты и обычные установки разрешаются автоматически. Root, heredoc или `python -c` сами по себе не означают опасность. Если модель недоступна/не определила риск, требуется подтверждение.

## Запреты

Встроенная защита запрещает уничтожение системных/домашних/корневых каталогов, форматирование, запись на диски, fork bomb, убийство всех процессов и выключение/перезагрузку машины. `approvals.deny` дополнительно блокирует DROP DATABASE, DROP SCHEMA, TRUNCATE TABLE, wipefs и blkdiscard: кнопки, постоянное разрешение и режим без запросов их не отменяют.

Модель также запрещает утечку секретов, отключение защиты и уничтожение бэкапов. Её отказ владелец технически может разово переопределить, в отличие от жёсткого запрета. Шаблоны deny не являются полной песочницей: не обещай блокировку любого опасного кода.

## Кнопки

Не подтверждайте непонятную команду: отклоните и попросите объяснить последствия/откат.

| Выбор | Действие |
|---|---|
| Один раз | Только текущая операция |
| На сеанс | Соответствующий шаблон до конца сеанса |
| Всегда | Сохранить соответствующее разрешение; не для непонятных команд |
| Отклонить / нет ответа 5 минут | Не выполнять |

## Настройки

`approvals.mode: smart`, `auxiliary.approval.provider: openai-codex`, `auxiliary.approval.model`: модель, выбранная в конфигурации экземпляра, `display.language: ru`, `security.redact_secrets: true`.

Русский действует на поддерживаемых поверхностях этого профиля. Код, команды, пути и сообщения внешних программ не переводятся; другие профили независимы. Изменения шлюза применяются мягким перезапуском после активных задач.
