HERMES: СПРАВКА

hermes — обычный разговор; задайте задачу своими словами.
hermes setup — начальная настройка
hermes model — модель/провайдер
hermes config show — настройки
hermes config set display.language ru — русский интерфейс
hermes config set stt.language ru — русское распознавание речи
hermes --help / hermes <команда> --help — справка, например hermes cron --help

Модель понимает запрос/готовит ответ; провайдер даёт доступ к ней; API-ключ — доступ к сервису. Инструмент — действие агента (файл, поиск, команда); шлюз — мессенджеры; профиль — отдельные настройки/история/подключения; сессия — разговор; задание по расписанию — действие в заданное время; расширение — новые возможности; навык — инструкция для задачи.

В ${HERMES_HOME}: config.yaml — настройки, SOUL.md — главные правила, locales/ — переводы, hermes-agent/ — исходники, backups/russian-localization/ — копия до русификации. Постоянные файлы — usercustom/userdata/files/, личные правила — usercustom/userdata/instructions/.

Русский включён в этой установке. Язык, сохранённый браузером/desktop, может иметь приоритет: выберите «Русский» там. Команды, адреса, имена моделей и ваши файлы не переводятся; внешние сообщения/аварийная диагностика могут остаться английскими.

Русификация внесена в исходники: после обновления проверь язык, обновление может заменить файлы. Копия правок — рядом с резервной в russian-localization.tar.gz.
