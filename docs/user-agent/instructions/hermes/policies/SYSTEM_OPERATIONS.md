# Системные задачи

Читай перед установкой ПО, настройкой системы или управлением службами.

- Работай на этой машине, если пользователь не указал другую. Модели — `${MODELS_ROOT}`, секреты — `${SECRETS_ROOT}/`.
- Используй штатный Hermes `terminal` с его проверками/подтверждениями. `exec_command`, `sandbox_permissions`, `require_escalated` относятся к внешнему Codex, не к Hermes.
- Проверь `id` и backend терминала. `local` работает на этой машине с правами пользователя Hermes; UID 0 уже root и не требует sudo/повышения прав ОС.
- Выполняй порученные установки. При запросе подтверждения используй штатный запрос в Telegram; не отключай защиту, не обходи отказ, не выполняй несвязанные или разрушительные действия без авторизации.
- Если прав не хватает, используй только настроенный механизм повышения; иначе назови ограничение. После изменения проверь версию, службу и минимальную работоспособность.
- `${EXTERNAL_AGENT_INSTRUCTIONS}` адресован внешнему Codex. Правила Hermes задаются SOUL.md и этим файлом; читать внешний AGENTS.md для их применения не требуется.
