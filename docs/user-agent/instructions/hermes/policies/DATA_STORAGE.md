# Файлы и базы проектов

Читай перед созданием/переносом постоянных файлов, проекта или базы, настройкой контейнерного хранилища и подготовкой бэкапа.

## Файлы

Все постоянные пользовательские материалы сохраняй в `${HERMES_HOME}/usercustom/userdata/`. Проекты — `projects/<project>/` для исходников, конфигурации без секретов и SQL-миграций; вложения — `files/uploads/`, результаты — `files/exports/`, реестр баз — `files/admin/databases.json`. Подпапки допустимы. Нужные вложения копируй из кэша. Временные файлы и пересоздаваемые кэши могут быть снаружи, но постоянный результат перенеси внутрь до завершения задачи. Ссылка на внешний файл не включает его содержимое в бэкап; контейнеру подключай постоянную пользовательскую папку.

Личные правила и уроки сохраняй в `usercustom/userdata/instructions/`, дополнения — в `instructions/overrides/`, собственные навыки — в `usercustom/userdata/skills/`. Добавляй в ROUTING.md ссылку, назначение и условие чтения. Навыки подключаются штатной настройкой `skills.create_dir`. Для отдельного инструмента/генератора настрой и проверь фактическое подключение к файлу: само сохранение текста не означает применение. При настройке или переносе прочитай `${HERMESCUSTOM_ROOT}/ARCHITECTURE.md`.

## Supabase

Проверь подключения и имена; обычно выделяй проекту отдельную схему, при необходимости — базу с доступными правами. Не меняй системные схемы Supabase и MemOS. Записывай сервер, базу, схему, проект и способ доступа без секретов в `files/admin/databases.json`; миграции — в проект. При недоступности Supabase сообщи и восстанови подключение, не выбирай SQLite. Миграция внутренних SQLite Hermes/MemOS — отдельная задача.

## Бэкап

Файловый бэкап должен сохранять весь `usercustom/userdata`, включая будущие подпапки. Перед включением учти старые данные вне него. Состав — `${HERMES_HOME}/usercustom/userdata/files/admin/BACKUP_SCOPE.md`. Вся память включает записи, связи, векторы, область доступа и метаданные. Бэкапы этой инструкцией не настроены: проверяй расписание, успешную копию и восстановление.
