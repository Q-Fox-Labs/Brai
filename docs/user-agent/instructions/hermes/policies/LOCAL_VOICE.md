# Голосовые ответы: Silero

Читай для голосового ответа, образца, смены голоса или режима голос/текст. Используй локальную Silero, без Edge/облачной подмены. При сбое сообщи ошибку, не обещай несуществующую отправку.

## Режим

- `/голос`, «отвечай голосом», «перейди на голос» включают в текущем диалоге режим текста и голоса: в каждом ответе отправляй полный текст и голосовое сообщение с тем же смыслом. Подтверди включение текстом и голосом. Продолжай даже после текстового входа до `/текст` или явной просьбы отключить голос; выключение подтверди текстом.
- Только при явной просьбе отвечать исключительно голосовыми не отправляй обычный текст ответа. Просьба отвечать голосом сама по себе не отключает текст. При явной просьбе вернуть текст снова отправляй текст и голос; при просьбе оставить только текст отключи голос. Код, команды, ссылки и файлы при необходимости передавай текстом или вложением даже в режиме только голоса.
- Храни режим по истории, включая сжатую, только для этого участника/чата/темы. Не включай без просьбы; один образец не включает постоянный режим. Образец другого голоса не меняет основной; смена голоса не меняет режим.
- Эти русские сигналы распознаёт ассистент, если сообщение дошло до него: это не зарегистрированные команды gateway. Нативные команды `/voice tts` и `/voice off` управляют отдельным режимом gateway.

## Установка и состояние

Модель `${SILERO_MODEL_PATH}`, CPU PyTorch `${SILERO_VENV}`; TTS локальный. Лицензия CC BY-NC 4.0 ограничивает коммерческое использование. WAV: 8/24/48 кГц; адаптер генерирует 48 кГц и OGG/Opus mono для Telegram.

Голоса: Айдар `aidar`, Байя `baya`, Ксения `kseniya`, Евгений `eugene`, Ксения два `xenia`. «Ксения» без ID неоднозначна — уточни. Список проверяется `silero-tts --list-speakers`.

- Источник актуального голоса: `hermes config get tts.providers.silero.voice`. Эта строка — сохранённое отображение состояния; после смены обнови её.
При переносе проверь целевой профиль: старые участники и режимы не переносятся.

## Текст

Вход — кириллица, без латиницы, цифр, эмодзи, разметки, кода и нераскрытых символов. Иностранные слова переведи или запиши произношение кириллицей. Числа сначала представь английскими словами, затем кириллицей: `5 → five → файв`, `12 → twelve → твэлв`, `2026 → two thousand twenty six → ту таузэнд твэнти сикс`; передай только итог. При явной просьбе читать числа по-русски следуй ей.

Значимые символы и адреса проговори словами, ненужные слуху детали опусти. Не пропускай иностранные слова: `casual → кэжуал`. Пунктуация для пауз допустима. Перед каждым вызовом TTS проверь весь текст на латиницу и цифры. Если получил `VOICE_TEXT_REQUIRES_CYRILLIC`, исправь текст и повтори синтез. Длинный ответ дели по предложениям до 900 символов, не обрезай смысл.

## Генерация и смена голоса

Настройки: `tts.provider: silero`, command-provider `tts.providers.silero`, `voice_compatible: true`, `output_format: ogg`.

1. Прочитай текущий голос. Для смены без имени предложи остальные четыре; неизвестный голос не подменяй, для «Ксения» уточни ID.
2. Постоянная смена: `hermes config set --force tts.providers.silero.voice ID`, read-back того же ключа и обновление строки состояния. Другие настройки не меняй. Образец передавай адаптеру с отдельным голосом, не меняя default.
3. Вызови `text_to_speech`, проверь Silero, существование/непустоту и декодирование файла. В режиме текста и голоса включи полный текст ответа в итоговое сообщение. Для доставки голоса добавь отдельные строки `[[audio_as_voice]]` и `MEDIA:/абсолютный/путь.ogg`.
4. При старом кэше или для образца создай UTF-8 вход в `${HERMES_HOME}/cache/scratch` и вызови `python3 ${HERMES_HOME}/scripts/silero_voice.py --input INPUT --output OUTPUT.ogg --voice ID`. Проверь результат; не переходи на облако.

Предупреждение валидатора вложенного `providers` не доказывает отсутствие command-provider: используй штатный `hermes config set --force`, read-back и реальный синтез, не ручную правку YAML. Сохранение настройки не доказывает доставку аудио.
