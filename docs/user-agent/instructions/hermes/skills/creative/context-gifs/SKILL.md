# GIF в разговоре

Генерируй GIF, когда движение помогает объяснить мысль, поддержать шутку или выразить уместную реакцию. Выбирай один понятный сюжет по текущему диалогу: например, очередь задач как конвейер, цикл обратной связи или кот, празднующий завершение работы. Не добавляй GIF ради заполнения ответа.

## Уместность

- Дневной квоты и обязательной периодичности нет. В большинстве ответов достаточно текста. Не вставляй автоматически GIF подряд; после своей GIF дай разговору продолжиться. Не предлагай генерацию в каждом ответе.
- Не добавляй автоматические мемы при горе, конфликте, тревоге, срочной проблеме, обсуждении здоровья, денег или другой чувствительной темы. Не передавай генератору личные данные из разговора; придумай обезличенный сюжет.
- Одна короткая петля, одно действие, спокойное движение, без вспышек и длинных надписей. Для объяснения сохраняй смысловую точность; мем не должен высмеивать собеседника.
- Если уместность сомнительна, отвечай текстом. Явная просьба пользователя о GIF имеет приоритет над рекомендацией частоты, но не над доступами.
- Автоматическая генерация — одна попытка. При ошибке продолжи обычный ответ без повторов, смены провайдера, просьб о ключе и платного запасного маршрута.

## Настройка обычными словами

Получай scope из доверенной идентичности текущего собеседника: например, telegram:user:<user_id>. Для одного пользователя сохраняй один scope в разных сессиях. Если идентичность неизвестна, не генерируй автоматически и не меняй чужую настройку.

Используй установленный scripts/context_gif.py из профиля Hermes. status, off и rare работают без движка и генератора:

```sh
python3 "$HERMES_HOME/scripts/context_gif.py" status --scope '<scope>'
python3 "$HERMES_HOME/scripts/context_gif.py" off --scope '<scope>'
python3 "$HERMES_HOME/scripts/context_gif.py" rare --scope '<scope>'
```

- «Выключи гифки», «без мемов и анимаций» → off. Подтверди после успешной записи. Это запрет самостоятельных GIF, не запрет явно запрошенных.
- «Можешь снова иногда присылать гифки» → rare.
- «Сделай GIF про…» → once с конкретным сюжетом; off остаётся выключенным.
- Перед самостоятельной GIF проверь status и используй auto. Не называй выключение временным и не заменяй его одной записью в памяти.

## Генерация по подписке

Выбери Python установленного движка Hermes и фактический engine-root текущего экземпляра по его конфигурации. Не угадывай путь и не читай .env/credentials. Передай действующий HERMES_HOME. Пример с заполнителями:

```sh
<python-Hermes> "$HERMES_HOME/scripts/context_gif.py" once --scope '<scope>' --engine-root '<engine-root>' --prompt 'Кот поднимает лапы, радуясь завершённой задаче; мягкая короткая петля'
```

Для самостоятельной вставки используй auto вместо once. Скрипт требует уже выбранный image_gen.provider=openai-codex. Он запрашивает готовую GIF из девяти кадров по 200 мс (1,8 секунды) у подписочного Images endpoint Codex. Байты ответа сохраняются без перекодирования и сборки кадров. Подписка остаётся единственным способом авторизации; ключи не добавляй и config.yaml не переключай. Codex сам выбирает серверную модель; не утверждай, что принудительно вызван Flare 2.6.

Если содержание результата не соответствует запросу, не отправляй его автоматически. Готовую GIF опубликуй через Brai publish_file и используй точный возвращённый дескриптор. published:false означает, что сборка ещё не опубликовала результат. Не используй MEDIA с локальным путём вместо публикации.

## Images 2.6 и другие задачи

В [анонсе OpenAI](https://openai.com/index/introducing-images-2-6/) Images 2.6 доступны в ChatGPT и Codex по подписке; отдельные Flare и Sunburst предлагаются в API. Скрипт добавляет недостающие в текущем Hermes параметры подписочного запроса: output_format=gif, frame_count и frame_duration_ms. При отказе сервера не заменяй нативную генерацию сборкой отдельных кадров.

Images 2.6 также улучшает согласованность при редактировании; в API есть complexity, markup и SVG. При явном запросе графики учитывай эти возможности: Flare для быстрой работы, Sunburst для точной детальной графики, low complexity для простых правок. Проверяй фактическую схему установленного инструмента: ссылка на анонс не добавляет ему параметры. Не включай API ради этих возможностей. Постеры и другую графику веди по навыку art-director; эта политика не заменяет его.
