# Проверка установленного MemOS

Этот файл задаёт порядок диагностики. Наличие исходников или навыка не подтверждает включённость сервиса.

Проверь адреса REST API, embeddings и bridge по конфигурации активного профиля. Версии исходников, API health и OpenAPI могут отличаться. Проверь владельца и область кубов через действующий реестр; не приравнивай технический ID к человеку.

Для проверки storage используй тестовые данные и полный цикл add → read-back → search → удаление явно названного тестового ID → read-back. Проверяй scope независимо от других фильтров и считай уникальные ID: один результат может дублироваться в нескольких корзинах.

Отдельно проверь startup recall, turn sync и фактически загруженный provider. Наличие SKILL.md или клиента не подтверждает интеграцию. Проверяй модальность по health сервиса, а весь путь от Hermes — по действующему адаптеру. Текстовая транскрипция не означает сохранение аудио или изображения.

Точные адреса, роли, таблицы и история замеров принадлежат документации экземпляра. При переносе текущего профиля эти сведения сохраняются как локальные дополнения; настройки другого аккаунта не наследуются. Не вмешивайся в работу другого профиля или агента.
