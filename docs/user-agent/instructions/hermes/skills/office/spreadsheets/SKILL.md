name: spreadsheets
description: Создавать и присылать файлы Excel XLSX, в том числе тестовые, из таблиц с текстом и числами.
---

Для создания обычной книги Excel уже есть готовый помощник
`${HERMESCUSTOM_ROOT}/skill-scripts/office/spreadsheets/scripts/xlsx.py`.
Он работает на стандартном Python без openpyxl, xlsxwriter и установки пакетов.
Отсутствие этих библиотек не означает, что создание XLSX недоступно.

Вход помощника — JSON `{"sheets":[{"name":"Тест","rows":[["Товар","Количество"],["Пример",2]]}]}`.
Можно передать несколько листов. Ячейки: строки, числа, true/false и null.
Создавай временный файл в рабочем каталоге текущего поручения. Вызов через
execute_code позволяет сразу передать данные без промежуточного JSON:

```python
import os, runpy
from pathlib import Path
writer = runpy.run_path(str(Path(os.environ['HERMESCUSTOM_ROOT']) / 'skill-scripts/office/spreadsheets/scripts/xlsx.py'))
receipt = writer['create_workbook'](
    {'sheets': [{'name': 'Тест', 'rows': [['Товар', 'Количество'], ['Пример', 2]]}]},
    Path.cwd() / 'test.xlsx')
print(receipt)
```

Либо запусти тем же установленным Python `xlsx.py --input table.json --output test.xlsx`.
Не перезаписывай существующий файл: выбери новое имя. После успешного создания
передай точный путь штатному publish_file и верни его опубликованный дескриптор.
Сам путь и сообщение об успехе помощника не заменяют доставку файла.

При просьбе «пришли тестовый Excel, если инструмента нет — не делай» используй
этот готовый помощник и небольшие вымышленные данные. Пользователь не должен
указывать способ сборки, ставить пакеты или составлять техническое задание.

Ограничения: до 20 листов и 100000 ячеек; текст до 32767 UTF-16 единиц,
целые числа до 15 цифр. Длинные идентификаторы передавай строками.
Текст, начинающийся с =, +, - или @, сохраняется буквальным текстом.
Помощник не редактирует существующие книги, не создаёт формулы, диаграммы,
макросы или оформление. Для такой задачи сначала проверь другие доступные
средства и прямо укажи неподдерживаемую часть; не подменяй её молча CSV.
