# Silero: синтез и смена голоса

Для голосового ответа, образца, смены голоса или режима сначала полностью прочитай `${HERMES_HOME}/LOCAL_VOICE.md`. Это единственный источник общих правил режима, подготовки текста, выбора голоса и доставки; текущее значение проверяй штатным config get. Не копируй эти правила сюда.

Локальная Silero без Edge/облачной подмены. Для обычного синтеза используй text_to_speech по LOCAL_VOICE.md. Для прямого адаптера, образца или диагностики кэша прочитай [технические команды](references/local-synthesis.md). Образец передаёт отдельный voice, не меняет default и не включает постоянный режим.

Перед отправкой проверь непустой декодируемый файл и доставку; сохранённая настройка не доказывает отправку аудио. Настройки меняй штатно, не ручным YAML; предупреждение схемы проверяй read-back и реальным синтезом. При сбое сообщи ошибку без обещания отправки. Истёкшее/отклонённое одобрение правки инструкции не обходи; назови неизменённый файл отдельно от успешных изменений.
