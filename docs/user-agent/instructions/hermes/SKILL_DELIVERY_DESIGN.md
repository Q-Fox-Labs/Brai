# Отдельная поставка навыков Hermes

Это проектное решение; действующая поставка Hermes не меняется до реализации и приёмки.

## Граница

Версионируемый компонент инструкций содержит индекс, базовые тексты, политики, навыки и связанные справочники. Он не содержит runtime, плагины, пользовательские файлы, память и секреты. Перемещение только навыков недостаточно: индекс и его относительные ссылки должны поставляться как согласованная версия.

CI собирает независимый неизменяемый артефакт из явного списка файлов и связывает его digest с проверенным коммитом. Установщик проверяет источник, manifest, хеши, размеры и безопасные пути; выбирает только изменившийся компонент. Зависимости и конфигурация экземпляра задаются оператором, а не текстами.

## Подключение и откат

Профиль ссылается на стабильный каталог инструкций через управляемый маршрут. Установщик проверяет текущую квитанцию и известный управляемый блок SOUL, готовит новый каталог целиком и атомарно переключает указатель. Личные инструкции, пользовательские навыки и текст вне управляемого блока остаются на месте. Неизвестное состояние останавливает обновление без перезаписи. После переключения проверяются содержимое по manifest, доступность индекса для владельца профиля и ссылки на навыки. До подтверждения сохраняется прежняя версия; при известном текущем состоянии откат возвращает прежний указатель. Неизвестный исход сначала сверяется.

Новая сессия читает установленный индекс; уже работающая сессия может сохранять старый контекст. Обновление инструкций само по себе не перезапускает gateway и не меняет плагины, если отдельная проверка движка подтвердит, что маршруты читаются при новом запуске сессии. Доступность генератора изображений определяется фактическими подключениями.

## Переход и приёмка

Сначала подготовить компонент и его входы, не удаляя тексты из старой поставки. Для DEV и клиентского установщика добавить выбор проверенного пакета и обратимый переход с текущего маршрута; согласовать обновление обоих операторских плейбуков Admin. Проверить первый переход, повтор, восстановление после прерывания до и после смены указателя, отказ при неизвестной правке, конфликт личных файлов, откат и восстановление на чистой установке. На живом тестовом экземпляре подтвердить чтение навыка новой сессией без перезапуска Hermes. Только затем исключить тексты из payload адаптера и проверить, что изменение одного навыка не меняет его digest.

Совместимость для старых установок сохраняется до принятого перехода. Один Git SHA и доказательство CI должны однозначно связывать версию индекса с версией навыков. Время проверки и переключения измеряется отдельно от очереди, CI и остальных компонентов; целевой срок задаётся после замера.
