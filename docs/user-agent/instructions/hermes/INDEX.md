# Инструкции пользовательского агента

Системный загрузчик личного профиля подключает этот индекс и [BASE.md](BASE.md) независимо от пользовательских файлов. USER.md и SOUL.md содержат личные сведения и предпочтения; агент пользователя может менять их по его поручению. В начале сессии полностью прочитай личный `${HERMES_HOME}/usercustom/userdata/instructions/ROUTING.md`. Затем загружай подходящие задаче инструкции по этому индексу. При обрезке дочитай файл до конца.

Устройство источников и пользовательских дополнений — в [ARCHITECTURE.md](ARCHITECTURE.md). Настройки экземпляра, имя и доступность сервисов проверяй в действующем профиле; они не наследуются с текстами продукта.

## Навыки

Навыки и справочники обновляются отдельно как документация. По поручению владельца сохраняй самостоятельные текстовые правки напрямую в Git-документации, без feature-ветки, CI-сборки и пересборки Hermes; затем отдельно примени и проверь тексты. Это уточняет прежний общий порядок встроенных навыков в INSTRUCTION_CHANGES.md: базовые политики остаются в поставке, а тексты навыков — в отдельной документации. Скрипты по-прежнему проходят выпуск кода. Найди подходящий навык штатным поиском и открой его полным вызовом skill_view. Справочники читай по путям установленного навыка. Старые копии skills/ рядом с этим индексом могут сохраняться как история; не используй их вместо установленного навыка.

Для постеров, афиш и баннеров используй art-director. Для настройки и диагностики Hermes — hermes-agent. Для уместных GIF, мемов, объясняющих анимаций и их отключения — context-gifs. Наличие навыка не подтверждает доступность внешних программ. Добавление навыка не требует изменения этого индекса.

Промпт Telegram Business — [здесь](prompts/telegram-reply.md); отправка требует подтверждения владельца.

Документы установщика и правила разработки не являются инструкциями пользовательского агента. Секреты, память и переписка в этот раздел не переносятся.
