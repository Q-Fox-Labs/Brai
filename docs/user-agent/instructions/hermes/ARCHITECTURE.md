# Размещение инструкций Hermes

Общие инструкции пользовательского агента принадлежат Brai. Их исходники находятся в этом разделе; код расширений, рабочий профиль и пользовательские данные хранятся отдельно.

## Точка входа и чтение

При каждом ходе загрузчик личного Hermes проверяет защищённую общую поставку и включает в системный контекст `context.md`, `INDEX.md`, `BASE.md`, `BUG_HUNT.md` и инструкцию навыка `context-gifs`. Недоступный, пустой или недоверенный обязательный файл останавливает сборку контекста. Остальные инструкции агент открывает по условиям индекса; личный ROUTING.md он читает в начале сессии.

Личные USER.md и SOUL.md необязательны и доступны владельцу для редактирования. Их актуальное содержимое подключается отдельно и не отменяет общие правила. AGENTS.md внешнего движка адресован разработчику и не заменяет системные инструкции.

## Состав

| Источник | Назначение |
| --- | --- |
| [INDEX.md](INDEX.md) | Условия чтения политик и каталог навыков |
| [BASE.md](BASE.md) | Общие правила |
| [BUG_HUNT.md](BUG_HUNT.md) | Обязательный протокол наблюдений о сбоях |
| policies/ | Правила файлов, инструкций, системных действий, имени, памяти, секретов, разрешений и голоса |
| skills/ | Канонические тексты навыков со справочниками; скрипты находятся в коде расширений |
| [Промпт Telegram Business](prompts/telegram-reply.md) | Правила генерации; подключение не разрешает отправку |
| docs/user-agent/usercustom/ | Локальные дополнения, исключённые из Git и поставки |

Все личные профили читают один защищённый системный каталог. Продуктовые тексты устанавливаются отдельно из Git-документации, встроенные навыки движка остаются защищённым резервом. Тексты не привязаны к владельцу профиля. Системный каталог имеет приоритет и не зависит от личных external_dirs, create_dir и disabled. Личные навыки читаются и создаются только в usercustom/userdata/skills своего профиля. Скрипты навыков подключены из принятого кода только для чтения.

## Версия и конфигурация

Базовые правила, политики, промпты и основной контекст входят в явный состав поставки Hermes. Их изменение меняет её идентичность. [Тексты навыков и справочники](../../skills.md) обновляются независимо из Git-коммита документации; их изменение не меняет сборку и payload адаптера. Скрипты навыков остаются в коде. Справочные карточки и личные дополнения в неё не входят. Агент читает установленную версию. Правка DEV checkout сама по себе не активирует инструкции.

Обозначения ${HERMES_HOME}, ${SECRETS_ROOT}, ${MODELS_ROOT}, ${HERMES_DB_COMMAND}, ${MEMOS_API_URL}, ${MEMOS_EMBEDDINGS_URL}, ${MEMOS_BRIDGE_URL}, ${SILERO_MODEL_PATH}, ${SILERO_VENV} и ${YTDLP_DOWNLOAD_ROOT} относятся к конфигурации экземпляра. Не выводи из примеров имя владельца, права SQL, состояние сервисов или факт бэкапа.

При переносе существующего профиля сохраняются его полные действующие тексты, включая личные и инфраструктурные отличия. Публичный шаблон не заменяет их автоматически. Квитанция хранит идентичность источника и hashes установленного набора; неизвестный управляемый блок требует разбора.

## Личные материалы

Runtime HERMES_HOME/usercustom содержит код надстроек и userdata; его целиком не переносят в docs/. Пользовательские файлы и материалы проектов постоянно хранятся в Артефактах; рабочие копии временные. Личные инструкции и ROUTING.md — в userdata/instructions, собственные навыки — в userdata/skills. Их подключает штатная настройка skills.create_dir.

Документационный usercustom предназначен для локальных дополнений. Он не заменяет профиль, память, переписку, авторизацию или файлы. Его сохранение и подключение выполняются явно.

При обновлении сохраняй личные USER.md, SOUL.md и пользовательские навыки. Перед заменой правила прочитай [INSTRUCTION_CHANGES.md](policies/INSTRUCTION_CHANGES.md). Прежний набор сохраняется до проверки подключения и отката.

Независимое обновление навыков описано в [каталоге](../../skills.md). Прежний [проектный вариант](SKILL_DELIVERY_DESIGN.md) не определяет текущий контракт.
