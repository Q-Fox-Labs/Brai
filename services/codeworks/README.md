# Codeworks

Codeworks управляет рабочими областями и выпуском компонентов. Codex и Hermes используют один серверный процесс; подключаться к нему можно с разных компьютеров без настройки Codeworks на каждом клиенте.

Чтение не создаёт рабочую область. Перед первой записью вне разрешённых исключений создаются отдельная ветка и worktree. Документационные исключения задаёт оператор.

После проверки Codeworks выпускает только изменившиеся компоненты и удаляет завершённую область. Подробности API и жизненного цикла описаны в [контракте](CONTRACT.md).
