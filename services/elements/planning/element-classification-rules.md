# Классификация Элемента

Версия 0.8. Рабочая модель. Выбирай минимальный достаточный уровень.

1. Выдели самостоятельные предметные итоги. Каждый станет Задачей. Исследование, обсуждение и выбор по одному вопросу оставляй вместе.
2. Отдельно порученные выбор подхода, выбор источника и применение выбранного источника — разные итоги. Если способ уже задан, выбор предложения и подготовка входят в его применение.
3. Подготовка, исполнение, проверка и фиксация одного практического итога — одна Задача. Самостоятельно заданный результат для основного объекта и общий результат для остальных — разные Задачи. Повторение по нескольким однотипным объектам раскрывай Ходами.
4. Объединяй 2–6 Задач в Цель, если вместе они дают один пригодный основной ресурс или его готовность к использованию. Получение ресурса и его оснащение для работы могут быть разными Целями, если каждое требует нескольких Задач и имеет собственный принимаемый итог.
5. Объединяй 2–6 таких Целей в Квест. Один ребёнок не повышает уровень. Не дроби работу ради нужного числа детей.

Длительность, исполнители и число Ходов не определяют уровень. Если итог неясен, не угадывай его: подготовь уточнение. Неизвестные параметры исполнения не мешают классификации понятного итога.

Классификация — этап Операции постановки. Она задаёт границы детей, а не создаёт их собственные Ходы. Заголовки обозначают короткий результат с предметом и конечным состоянием.
