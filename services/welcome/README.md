# Welcome

Справочная Brai в Telegram до подготовки личного профиля. Настройки модели и квоты принадлежат администратору. Заявка на гостевой доступ состоит из двух вопросов и подтверждения отправки.

Разрешённые входы, данные и эффекты описаны в [контракте](CONTRACT.md). PostgreSQL мигрирует отдельный owner-процесс. Runtime читает закрытую конфигурацию по пути WELCOME_CONFIG. Для модели используется выделенный запуск Codex с принятым помощником подписочной авторизации.

Проверка проекта: `npm test --workspace=@brai/welcome`.

Справочная получает [системную инструкцию](src/prompt.md) и [тексты справки](src/help.md) из поставки.
