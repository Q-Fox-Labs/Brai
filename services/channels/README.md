# Каналы: целевой контракт

[Контракт v1](CONTRACT.md) закрепляет операции, DTO, версии, правила и будущую связку с Приёмом. Это проект до реализации: отдельного действующего компонента, исполняемых программ, миграций и поставки Каналов нет.

Контракт включает короткие NATS Services операции и собственное хранение метаданных; исполнения Telegram и Temporal внутри Каналов нет. При реализации машинные AsyncAPI/JSON Schema должны соответствовать контракту. Действующий [Приём](../intake/README.md) пока использует другой общий DTO; переход описан в разделе 11 контракта и ещё не выполнен.
