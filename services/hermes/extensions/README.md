# Расширения Hermes

Исходники расширений принадлежат Brai. Внешние Hermes, MemOS и окружение Python устанавливаются и обслуживаются отдельно оператором. Наличие этих файлов не включает расширения в экземпляре. Порядок применения patches и происхождение исходников указаны в `provenance.json`.

Каталог содержит код, тесты, локализации и начальные шаблоны, но не содержит пользовательских данных, памяти, переписки или секретов. Рабочие инструкции агента находятся в `docs/user-agent/instructions/hermes`. `profile/userdata` содержит только начальные шаблоны; подготовка профиля сохраняет существующие файлы.

Описание плагинов: [Groq Voice](plugins/groq-voice/README.md), [MemOS REST](plugins/memos-rest/README.md), [Telegram Business](plugins/telegram-business/README.md). Начальные шаблоны профиля: [маршруты](profile/userdata/ROUTING.md), [область бэкапа](profile/userdata/BACKUP_SCOPE.md).

## Состав и подключение

`manifest.json` перечисляет в `runtimeFiles` файлы расширений, которые входят в поставку. Внешний `artifact-manifest.json` закрепляет их SHA-256 вместе с самим manifest. Оператор проверяет поставку целиком; структурная проверка исходного дерева не удостоверяет происхождение файлов.

`tools/connect.py --check` проверяет структуру и при наличии внешнего manifest сверяет хеши. `--plan` показывает изменения профиля без записи; `--apply` применяет их. `--instructions-root` задаёт путь к каноническим инструкциям, по умолчанию используются инструкции из той же поставки. Для замены отличающихся файлов требуется явный `--overwrite`: прежнее содержимое сохраняется в резервную копию профиля. Патчи движка применяет операторский процесс отдельно.

Фактическое переключение экземпляра выполняет оператор. Прежний способ установки production сохраняется до отдельного выпуска. Границы сервиса описаны в [контракте Hermes](../CONTRACT.md), общие инструкции — в [документации пользовательского агента](../../../docs/user-agent/README.md).
