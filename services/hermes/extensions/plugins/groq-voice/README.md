# Groq: голосовые сообщения

Провайдер Hermes `groq-normalized` выполняет два этапа:
- Groq `whisper-large-v3-turbo` распознаёт аудио.
- Groq `openai/gpt-oss-120b` нормализует расшифровку по `normalization.txt`.

Основная модель Hermes и TTS не меняются. Если нормализация не удалась или ответ обрезан, сохраняется исходная расшифровка. При сбое распознавания возвращается короткая ошибка без подробностей запроса.

Ключ читается только на сервере из `/etc/.secrets/groq.env` по умолчанию. Для отдельного экземпляра служба может задать абсолютный путь через `GROQ_VOICE_SECRET_FILE`. Требования к файлу сохраняются: обычный файл владельца процесса, права `600`, без перехода по символической ссылке. Его значение не передаётся в контекст нормализатора, историю, аргументы команд или вывод инструментов. Доступ к Groq — фиксированные HTTPS-адреса с проверкой сертификата, без перенаправлений и внешних прокси. Код не журналирует аудио, расшифровки или секреты. Не копировать ключ в репозиторий.

## Включение в целевом профиле

Сначала безопасно сохранить и проверить целевой ключ; чужие ключи при переносе не использовать. Затем:

```sh
hermes plugins doctor groq-voice
hermes plugins enable --no-allow-tool-override groq-voice
hermes config set stt.provider groq-normalized
hermes config set --force stt.groq-normalized.model whisper-large-v3-turbo
hermes config set --force stt.groq-normalized.language ru
```

В этой версии диспетчер STT заново читает настройки при каждом вызове и умеет заново обнаруживать отсутствующий провайдер. Новое расширение без Telegram callback может загрузиться штатно без перезапуска. Сообщение CLI о загрузке не заменяет проверку реальной регистрации и вызова `tools.transcription_tools.transcribe_audio(..., source='gateway')`.

Проверять отдельно: офлайн-тесты, настоящий запрос Groq, входной путь Hermes и реальное новое голосовое в Telegram. Без последнего не утверждать, что доставка от Telegram до ответа проверена.

## Нормализация

Промпт очищает повторы и слова-паразиты, сохраняет смысл и язык, переводит числительные в цифры, оформляет продиктованные домены, сохраняет значимые отрицания. Правило «Vork-3 → ворктри» действует только для подразумеваемого термина, не для посторонних имён или настоящих номеров версий. Расшифровка передаётся отдельным сообщением как данные, а не вставляется в системные инструкции. Это снижает риск выполнения вложенных указаний, но промпт не является абсолютной гарантией точности. При необходимости менять только `normalization.txt`; этот файл читается на каждый запрос.

Для отката переключить `stt.provider` на ранее подтверждённый рабочий провайдер; не менять основную модель, голос, разрешения или память.
