# Telegram Business

Бот наблюдает согласованные Business-чаты, после debounce готовит черновик и отправляет владельцу в DM кнопки Send/Edit/Discard. **Автоотправки нет:** каждое сообщение клиенту требует подтверждения владельцем; can_reply не заменяет согласие.

| Задача | Читать |
|---|---|
| Установка, требования, настройки/подключение | [Подключение](docs/setup.md) |
| Owner controls, callbacks, expiry, права, state, ограничения | [Управление и защита](docs/controls.md) |
| Приватный контекст/память, промпт, генератор, тесты | [Контекст и проверка](docs/context.md) |

Callbacks проверяют owner_user_id; без can_reply кнопка Send скрыта. Черновики имеют TTL, typing bursts объединяются. Рабочий промпт читается с диска: правка текста не доказывает изменение callback/доставки. Для личных замен читай INSTRUCTION_CHANGES.md; тестируй на синтетической истории без внешней отправки.
