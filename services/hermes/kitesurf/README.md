# Kitesurf

Kitesurf — отдельный браузерный инструмент для Hermes. Агент выбирает его для
открытых страниц и простых действий. Существующие `browser_*` используют Chrome;
они подходят для сложных сайтов и сохранённых входов. Сессии не объединяются.

Движок Cloudflare закреплён на `b9b904e208836b946c6ffc81832ac1ec576ece54`.
`build.sh` принимает абсолютные пути чистой копии исходников и нового каталога
результата. Для сборки нужны Git, Node.js 22+, npm и системные средства сборки;
pnpm и Bazelisk закреплены в `package-lock.json`. Результат содержит wasm,
статику и отдельно закреплённые runtime-зависимости. Команда не запускает
браузер и не устанавливает службу.

`engine.mjs` работает в отдельном сетевом пространстве. Внешние запросы идут
через существующий публичный egress Brai. Личный worker подключается к CDP через
свой Unix-сокет и локальный relay. `identity/kitesurf.py` формирует units, а
`identity/kitesurf_client.py` предоставляет MCP-инструмент. Включение требует
установки и привязки этих частей к профилю; наличие исходников их не включает.
Исходящий WebSocket транспорт пока не поддерживает.
