# Известные проблемы local-ai

Зафиксировано 2026-10-06. Выпуск завершён по прямому указанию пользователя выпустить текущую версию даже с неисправностями и записать проблемы отдельно. Полная первоначальная приёмка не завершена.

## Выпущенная версия

Production unit: `brai-local-ai-operation3-production.service`. Контейнер: `brai-local-ai-op3-main-8683b1d1`. Образ: `sha256:8b8e194120f3344a379fcf834618b497761258f2d1827e0e39d5343373162d4e`.

Созданы собственные БД/роли `local_ai`, перенесены проверенные веса обеих моделей, установлен постоянный запуск. Пользователь `local_ai` и его ACL добавлены в существующий NATS; отдельная сверка прошла. Контейнер работает с лимитами 4 CPU и 6 GiB. Доступ к API — через NATS, включая `brai.local_ai.v1.invoke.embed` и `brai.local_ai.v1.invoke.transcribe`.

## Сбои и незавершённые проверки

1. **Полный production API не подтверждён.** Первый проверочный запуск остановился при декодировании отчёта в Ansible. Перед второй попыткой отдельное чтение подтвердило отсутствие фактов всех трёх тестовых вызовов в истории и собственной outbox. После изменения декодера вторая попытка остановилась на проверке типа stdout и в обработчике ошибки. Причина этого сбоя не установлена. Успех production embeddings и распознавания не заявляется.
2. **Живая отмена GigaAM не принята.** Изолированный тест отмены завершился ошибкой; точная причина была скрыта `no_log`. Последующий observer не прошёл итоговые проверки. Физическое завершение группы процессов и очистка временных файлов этого случая не подтверждены.
3. **Неполная эксплуатационная приёмка.** На финальном экземпляре не завершены живые проверки deadline embeddings, таймеров простоя обеих моделей, `null`, очереди на границе таймера, повторной загрузки, отказа активного исполнителя и прерывания работающего сервиса. Исправление обновления таймера после загрузки опубликовано и проверено тестом; это не заменяет живую проверку всей матрицы.
4. **История и приватность требуют оставшейся проверки.** На итоговом экземпляре не завершены сценарий отключения истории, приём короткого Core NATS факта без reply и отсутствие накопления после разрыва и полный аудит БД/логов на отсутствие содержимого вызовов. Проверенные пустые outbox/history для конкретных тестовых ID не доказывают эти свойства целиком.
5. **Восстановление проверено частично.** На изолированном стенде восстановленные БД и веса прошли embeddings и короткое распознавание, одноразовый контейнер удалён и отдельно проверен. Полный путь отката рабочего выпуска и восстановление прерванной операции на финальном экземпляре не проверены.
6. **Оставлены тестовые артефакты изолированного стенда.** Сохранены публичные аудиофикстуры для отмены и границы длительности: `c8a5fc9d-3ed9-41ff-b486-b0c7fc4361a4`, `b77d19f4-4be0-47b5-a97b-c3badd32bbb6`, `8c266277-5916-44bc-953d-4e6a4ae01c39`. Их удаление через artifacts не выполнено. Артефакт ровно 180 секунд завершился deadline; 180 секунд плюс один кадр — `INVALID_ARGUMENT`. Успешное распознавание на самой границе не подтверждено.

Лимит 1000 строк и проход упрощения отложены по отдельному прямому указанию пользователя. В этом выпуске упрощение не выполнялось.

Source local-ai больше не использует durable outbox: контроль гарантированной доставки отменён согласованной семантикой best-effort истории. Локальные проверки source не закрывают оставшуюся функциональную приёмку финального образа или production.
