# Приватный Silero runner

Runner — дочерняя программа Local AI, без сетевого API и загрузчика моделей. Родитель управляет установкой, последовательной очередью, сроком операции и всей группой процессов. Контракт RPC находится в [openrpc.json](openrpc.json), закрытые схемы — в [schemas.json](schemas.json), профиль — в [silero_pytorch.json](../../profiles/silero_pytorch.json).

## Запуск и зависимости

`runner.py --model-path ABSOLUTE_INSTALLATION_DIR --revision REVISION --threads 4 --output-directory ABSOLUTE_PRIVATE_DIR --ffmpeg ABSOLUTE_EXECUTABLE`

Каталоги уже существуют. `model-path` содержит ровно выбранный файл `v5_5_ru.pt`. Revision равна `50081637b602126ee06cb3bc8a744d25651d2da1`: это первые 40 символов SHA-256 содержимого, а не Git revision внешнего репозитория. Перед `PackageImporter(...).load_pickle('tts_models', 'model')` runner проверяет размер 145420684 байт и полный SHA-256 из профиля. Модель загружается на CPU, число потоков PyTorch — четыре. Запуск завершается ошибкой, если модель не поддерживает `eugene`.

Нужны существующие Python 3.12, torch 2.8.0+cpu, numpy 2.2.6 и ffmpeg с libopus. Профиль описывает эти зависимости; он не создаёт новое Python-окружение. WAV пишет стандартный модуль `wave`, soundfile не нужен. Никаких файлов модели вне установки Local AI нет.

## Поток и владение результатом

`stdin JSON-RPC → проверка текста → apply_tts → временный PCM16 WAV → ffmpeg → audio.ogg → JSON-RPC путь → родитель Local AI`.

`health {}` возвращает готовность, model ID и закреплённую revision. `synthesize {text, voice:"eugene"}` принимает непустой текст до 900 Unicode codepoints, без NUL и surrogate codepoints. Исходный текст передаётся модели без усечения. Ответ содержит абсолютный `audio_path` и `mime_type:"audio/ogg"`; путь остаётся приватным для Local AI. Клиент не задаёт пути, параметры ffmpeg или имя результата.

Результат — mono 48 kHz OggOpus 32 kbit/s, не больше 64 MiB. Каждый принятый синтез удаляет предыдущий `audio.ogg`, создаёт отдельный временный каталог и после успешного кодирования атомарно переносит результат в фиксированный путь. При ошибке временные файлы удаляются. Родитель удерживает каталог до физического выхода всей группы процессов; готовое аудио существует до следующего синтеза или очистки родителем. Пакет из нескольких синтезов последовательно перезаписывает этот же файл.

ffmpeg не использует shell, принимает только локальный WAV через `file` protocol, не читает stdin и остаётся в группе процессов runner. Timeout ffmpeg — 180 секунд; родитель ограничивает всю операцию 180 секундами и подтверждает выход группы при отмене. Истечение срока RPC не доказывает остановку. Автоматического повтора нет; повторный id не подавляет вычисление.

## Транспорт и ошибки

Один UTF-8 JSON-документ на строку, максимум 65536 байт вместе с переводом строки. Длинная строка отбрасывается целиком. Запросы и элементы batch исполняются последовательно. Уведомление без `id` исполняется без ответа; batch только из уведомлений не выдаёт строку. Пустой batch — `-32600`, невалидный JSON — `-32700`, неизвестный метод — `-32601`, параметры — `-32602`, сбой модели, файлов или ffmpeg — `-32603`. Ответ содержит только безопасное стандартное сообщение, без исключения, текста или внутренних путей. Неизвестные поля конверта отклоняются.

stdout содержит только RPC. Вывод Python, native torch и ffmpeg подавлен; при ошибке запуска stderr получает фиксированное сообщение. Никаких текстов и аудио в диагностике нет. Проверки без весов и тяжёлых импортов: `python3 -m unittest discover -s services/local-ai/runners/silero -p 'test_*.py'`.
