# Планирование Цели

Версия 1.0. Применяй [единый алгоритм](game-planning-rules.md), [классификатор](element-classification-rules.md) и [формат](game-planning-format.md).

Операция постановки Цели возвращает поля Цели и 2–6 черновиков Задач. Для каждой выдели входы, ожидаемые выходы и границы. Порядок детей должен учитывать передачу их итогов.

Система создаёт: подтверждение постановки Цели → постановку и приёмку каждой Задачи → рассмотрение итога Цели → приёмку Цели. Постановка и приёмка Задачи — общие записи с этой Задачей. Если Цель вложена, её собственные граничные Операции уже принадлежат родителю.

Собственные Ходы Задач создаются в их Операциях постановки. Приёмка каждой Задачи ждёт решение по ней, приёмка Цели — по всей Цели. Полученный ребёнком внутренний отчёт не становится автоматически входом следующей Задачи.
