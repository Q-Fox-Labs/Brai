# Планирование Квеста

Версия 1.0. Применяй [единый алгоритм](game-planning-rules.md), [классификатор](element-classification-rules.md) и [формат](game-planning-format.md).

Операция постановки Квеста возвращает поля Квеста и 2–6 черновиков Целей. Выдели их входы, ожидаемые выходы и границы. Порядок детей должен учитывать передачу их итогов.

Система создаёт подтверждение постановки Квеста, постановку и завершение каждой Цели и завершение Квеста. Рассмотрение требуется при явно порученном принятии; предметный выбор выполняется отдельным Ходом. Граничные Операции общие с Целями. Сами Цели раскрываются по [правилам Цели](goal-planning-rules.md).

Если итог включает выбор, решение относится к конкретной Цели или Квесту. Решение по вложенному Элементу его не заменяет. Сейчас проверяем успешное прохождение; отказы детей остаются вне этой проверки.
