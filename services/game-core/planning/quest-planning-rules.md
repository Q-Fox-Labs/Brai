# Планирование Квеста

Версия 1.0. Применяй [единый алгоритм](game-planning-rules.md), [классификатор](element-classification-rules.md) и [формат](game-planning-format.md).

Операция постановки Квеста возвращает поля Квеста и 2–6 черновиков Целей. Выдели их входы, ожидаемые выходы и границы. Порядок детей должен учитывать передачу их итогов.

Система создаёт: подтверждение постановки Квеста → постановку и приёмку каждой Цели → рассмотрение итога Квеста → приёмку Квеста. Граничные Операции общие с Целями. Сами Цели раскрываются по [правилам Цели](goal-planning-rules.md).

Приёмка Цели ждёт решение по конкретной Цели. Приёмка Квеста — решение по всему Квесту. Решение по вложенному Элементу этого не заменяет. Сейчас проверяем успешное прохождение; отказы детей остаются вне этой проверки.
