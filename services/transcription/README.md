# Transcription: техническое устройство

Сервис координирует задания распознавания. [Контракт](CONTRACT.md) описывает запросы, результаты, ограничения, неизвестный исход и срок доступности текста. [Упаковка и конфигурация](PACKAGING.md) задаёт процессы coordinator/helper/local/external одного владельца.

Вход — готовый artifact и запрос с явным маршрутом. Локальные вычисления выполняет Local AI; сервис не создаёт второй модельный runtime. Форматы сообщений находятся в schemas/, миграции — в migrations/.

Сборка, проверки и состав поставки определены в [package.json](package.json) и [component.json](component.json). Интеграционные сценарии требуют изолированного окружения и не запускаются на пользовательских данных.
