# Карта Элементов

`/elements` получает личную карту через `GET /api/elements` и серверную проверку сессии. Game-core остаётся владельцем Элементов, Ходов, попыток и ресурсов. UI не создаёт копии записей и не меняет API ресурсов.

У каждого Хода один UUID и один владелец. Операции запуска и приёмки родителя также видны в карточке целевой Задачи. Это две проекции одной записи. Каждая карточка считает собственные показанные Ходы по predecessor; общие Ходы получают местный номер в обеих карточках. Предшественники, не показанные в текущей карточке, учитываются при обходе цепочки.

Стрелка связывает строки двух проекций одного общего Хода. Запуск идёт от родителя к Задаче, приёмка — от Задачи к родителю. Координаты концов измеряются по DOM строки и пересчитываются при изменении масштаба, перемещении карточек и росте содержимого. Другие зависимости на карте не выдумываются. У дочерней карточки есть переход к названному родителю; у запуска или приёмки родителя — переход к названной Задаче. Переход приближает выбранную карточку. Наведение или клавиатурный фокус на общей строке подсвечивает обе проекции и стрелку.

Карточки различают Операцию и Действие крупным знаком исполнителя и отдельной формой значка. Статус всегда имеет собственные подпись и знак, поэтому не теряется среди цветовых состояний. UUID, системные коды и поля API не показываются.

Начальная раскладка группирует родителя и его детей. Сохранённые вручную координаты и масштаб продолжают храниться в `localStorage` отдельно для аккаунта. Все Ходы остаются раскрытыми без внутренней прокрутки. Полотно занимает рабочую область; постоянная кнопка только одна — «Вся карта». Фон можно перетаскивать, колесо и клавиши `+` / `−` меняют масштаб, а верхняя строка карточки перемещает её.

Подробности открываются в боковой панели. Ресурсы показывают содержимое и происхождение; их API и ссылки остаются прежними. Для DEV сохранены четыре ручных статуса Элемента (`draft`, `active`, `completed`, `cancelled`) и четыре статуса Хода (`planned`, `claimed`, `succeeded`, `cancelled`). Ручной статус меняет только статус выбранной записи и не создаёт попыток, результатов или ресурсов.

Проверка модели: `node --test apps/web/tests/elements-board.test.ts`. Полную визуальную приёмку выполняют в настоящем браузере.
