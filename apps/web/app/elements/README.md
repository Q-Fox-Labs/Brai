# Карта Элементов

`/elements` — карта в общей оболочке Brai. `screen.tsx` принимает `BoardData` и строит карточки по ID. В `demo.json` находится обезличенная симуляция конечного снимка: G1, три Задачи, 23 выполненных Хода и 26 ресурсов. Это исторический пример, а не данные текущего аккаунта. Реальные API, БД, платежи и действия не подключены.

Ход показывается в карточке владельца. Целевой Элемент и предшественник указаны отдельно в подробностях. Входы попытки содержат все накопленные ссылки; ресурсы раскрывают содержание и создавшую попытку. Приёмка остаётся у Цели. Её выход одновременно является результатом дочерней Задачи.

Пунктирные стрелки показывают родителя и детей. Сплошные стрелки показывают передачу результата следующей Задаче и возврат родителю при приёмке. Накопленные транзитивные входы не дублируют линию следующей Задачи. Полный набор доступен в подробностях Хода.

Фон можно тянуть, колесо и кнопки меняют масштаб, верхняя строка перемещает карточку. «Вся карта» показывает общий вид; список «К Элементу» приближает выбранную карточку. Стрелки клавиатуры перемещают сфокусированное полотно или верхнюю строку карточки. Раскладка, масштаб и положение просмотра сохраняются в localStorage отдельно по аккаунтам. «Сбросить раскладку» возвращает исходную геометрию. Сохранённые данные не меняют зависимости. Блокировка localStorage оставляет карту работоспособной в памяти и показывает сообщение.

Проверки геометрии и целостности примера: `npm run test:web`. Проверка взаимодействий требует настоящего браузера.
