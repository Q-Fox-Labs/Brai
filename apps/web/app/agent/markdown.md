# Markdown и диаграммы Mermaid

`markdown.tsx` отображает ограниченный Markdown. Сырой HTML остаётся текстом.

Диаграмма Mermaid запускается после закрывающей строки блока кода. Пока блок
не закрыт, отображается постоянная подпись ожидания. Ключ диаграммы зависит от
начала блока; продолжение ответа не пересоздаёт законченную диаграмму.

Mermaid использует строгий режим безопасности и настраиваемую тёмную тему
`base`. Временный контейнер рендера находится вне видимой области и удаляется
после успеха или ошибки. Отменённый рендер не обновляет сообщение. Ошибка
показывается внутри блока вместе с исходным кодом.

Кнопка «Развернуть диаграмму» открывает модальное окно на весь экран. Оно
использует уже готовый SVG без повторного рендера Mermaid. Доступны увеличение,
уменьшение, исходный масштаб, вписывание и перемещение перетаскиванием или
прокруткой. Клавиши `+`, `−` и `0` управляют масштабом; Escape закрывает окно.
При закрытии фокус возвращается к кнопке открытия. Кнопки доступны на сенсорном
экране. Оформление может отличаться от других клиентов Mermaid: результат
зависит от версии библиотеки, темы, раскладки и настроек исходной диаграммы.
