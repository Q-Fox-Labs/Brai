# Дневник

Дневник — раздел Web с постоянным хранением через контракт Artifacts. Отдельный
процесс и отдельная база не нужны: оригиналы, текст и связи принадлежат одному
штатному хранилищу. Обсуждений, запуска агента и автоматической отправки данных
провайдерам нет.

Владелец берётся только из проверенной сессии. Запись — неизменяемый JSON-файл
Artifacts с source=diary и kind=original. Он содержит версию, заголовок, явную
дату либо null и точный текст. Файлы записи имеют source=diary:<artifactId>
и сохраняются как original без преобразования. Исходная расшифровка и правка
могут быть отдельными материалами; прежние байты не перезаписываются.

Запись сохраняется до загрузки вложений. Каждый подтверждённый файл сразу
виден при повторном открытии записи. Неполная загрузка не считается успехом.
Создание повторяется с прежним ключом и теми же данными; конфликт даёт 409.
Чтение и загрузка проверяют владельца, источник, состояние и контрольную сумму.
Операций удаления, редактирования и внешних публичных ссылок в этом разделе нет.
Пределы файлов и гарантии долговечности задаёт services/artifacts/CONTRACT.md.

## HTTP

Все ответы private/no-store. JSON требует Content-Type application/json. Операции
кроме файлов требуют x-brai-user, совпадающий с ID проверенной сессии; поле не
выбирает владельца. Мутации проверяют Origin. Файл требует сессию и account query.

| Метод и путь | Вход | Результат |
| --- | --- | --- |
| GET /api/diary?offset=0 | Страница по 50 | entries и total без полных текстов |
| POST /api/diary | requestId UUID, title, date YYYY-MM-DD/null, text | entry сохранённого оригинала |
| GET /api/diary/entry?id=UUID&offset=0 | UUID, страница материалов | Точный текст и готовые материалы |
| POST /api/diary/materials?entry=UUID | requestId UUID, filename, mimeType, role | Подготовленный материал |
| PUT /api/diary/upload?entry=UUID&material=UUID | Байты, x-content-size | Готовый материал после проверки размера и SHA-256 |
| GET/HEAD /api/diary/file?entry=UUID&material=UUID&account=ID | download=1 либо один Range | Оригинальные байты |

role: original/transcript/correction. Лишние JSON-поля отклоняются. Неизвестная дата
остаётся null. Текст сохраняет пробелы и абзацы; максимум — 8 388 608 UTF-16 единиц,
JSON — 16 МиБ. Непустые файлы принимаются потоком до 2 ГиБ; Artifacts может уменьшить
предел. Загрузка не буферизует файл целиком в браузере или Web.

Ошибки: 400 INVALID_ARGUMENT/INCOMPLETE_FILE, 401 ACCOUNT_CHANGED/UNAUTHORIZED,
403 ORIGIN, 404 NOT_FOUND, 409 CONFLICT/CONTENT_CONFLICT/NOT_READY, 413 TOO_LARGE,
502 BAD_REPLY/INTEGRITY, 503 UNAVAILABLE/NOT_CONFIGURED/UPLOAD_UNCONFIRMED.
Ошибки Artifacts сохраняют его status/code. Сеть может скрывать успешный commit;
повтор использует прежние requestId и данные. Повтор готовой загрузки проверяет
новые байты и никогда не заменяет оригинал. Частично принятые файлы остаются
у записи; остальные можно загрузить повторно. Активные форматы скачиваются.

Резервирование включает согласованные БД и каталог файлов Artifacts. Git содержит
только код. Функциональная модель восстановлена по Brai_september, commit
64c26febe00d907c025fb44d3b39121536624636, diary-service и app/diary.
Старый runtime, Groq/Codex-обработчики и chat-модули в поставку не включены.
