# Дневник в Web

Web предоставляет авторизованный потоковый proxy и экран отдельного
[сервиса Diary](../../../../services/diary/CONTRACT.md).
Владельцем записей, очереди, raw и исправленного текста является Diary;
форматы определены в его [HTTP-контракте](../../../../services/diary/contracts/http.openapi.json).

## Путь пользователя

Пользователь выбирает аудио. Web создаёт намерение, передаёт файл, показывает
процент передачи, затем этапы серверной обработки и запись. Готовая запись
показывает исправленный текст, отдельно исходную расшифровку и свидетельство даты;
оригинал доступен для прослушивания через авторизованный proxy.
Неизвестная дата отображается явно. Ручной редактор, обсуждения и вложения
прежнего прототипа не предоставляются.

Стабильный requestId и метаданные хранятся локально отдельно для аккаунта и
отпечатка name/size/lastModified. Повтор выбора того же файла использует прежнее
намерение. Это не вычисление SHA-256 и не продолжение с места обрыва.
На сервере размер и SHA-256 проверяются отдельно. После ready повторного PUT нет.
Файл отправляется целиком; после приёма сервер продолжает работу без вкладки.

## Proxy

Все операции проверяют текущую Auth-сессию. JSON/загрузка требуют x-brai-user;
нативное audio использует account query, сверяемый с той же сессией.
Заголовок не даёт выбрать другого владельца. Мутации проверяют canonical Origin.
Адрес Diary задаётся DIARY_SERVICE_ORIGIN конфигурацией сервера; клиент его не выбирает.

| Метод и путь Web | Путь сервиса |
| --- | --- |
| GET/POST /api/diary | /v1/entries |
| GET /api/diary/entry?id=UUID | /v1/entry/UUID |
| POST /api/diary/materials | /v1/audio |
| PUT /api/diary/upload?entry=UUID | /v1/upload/UUID |
| GET/HEAD /api/diary/file?id=UUID&account=ID | /v1/file/UUID |

Список запрашивается offset-страницами по 50, без обещания total.
Подготовка аудио возвращает entry и ready; PUT возвращает 202 accepted, что
не означает готовность текста. Заголовки Range и x-content-size передаются сервису.
Ответы private/no-store; ошибка отсутствующей конфигурации — 503 NOT_CONFIGURED,
смена аккаунта — 401 ACCOUNT_CHANGED.

Экран сбрасывает данные и отменяет свои запросы при смене аккаунта.
Фоновые чтения не меняют записи и не запускают модель. Web не подключается
к БД Diary или моделям напрямую.
