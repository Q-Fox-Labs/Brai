# Дела

Раздел `/do` использует исходные компоненты задачника `Q-Fox-Labs/Brai_september`, коммит `64c26febe00d907c025fb44d3b39121536624636`. Разметка строк, меню, блокеров, описания, результата, структуры, проектов и панели подробностей перенесена из исходников. Сохранены размеры, отступы, индикаторы, шрифт Manrope и мобильные панели. Общая навигация Brai называет раздел «Дела»; палитра ограничена тёмной темой.

## Взаимодействия

Миссия содержит квесты, квест — цели, цель — задачи. Каждый вид может находиться в корне. Кружки показывают состояния непосредственных детей. Выполненные и отменённые задачи закрывают прогресс. Активный блокер запрещает завершить зависимый элемент; ссылки открывают связанные записи.

Исходные редакторы показывают заголовок, описание и результат без рамки и дополнительного отступа. Курсор заголовка ставится в точку клика по тексту: применён исходный помощник `detailOffsetAtPoint`, уже использовавшийся в описании и результате. Это явное исправление по требованию пользователя; исходный September ставил курсор заголовка в конец. Enter делит заголовок и создаёт соседний черновик, Shift+Enter открывает описание, Cmd+Enter создаёт вложенный элемент подходящего вида, Escape отменяет изменение. Черновик сохраняется при потере фокуса.

Свободная область строки открывает подробности. Меню, вкладки, формы, раскрытие ветвей и обработчики переноса взяты из оригинала. Перенос меняет порядок соседей или родителя подходящего уровня. Зоны у контейнеров выносят запись в корень; перенос на проект меняет проект всей корневой ветви. Автопрокрутка использует исходные пороги и скорости: 72 px/s в пределах 64 px, 216 px/s в пределах 28 px. Завершение переноса останавливает её.

В строке показывается постоянный числовой ID; в подробностях — относительный номер `M/Q/G/A-ID` с позициями потомков. Поиск по ID раскрывает родителей. Проекты можно добавлять и переставлять. Комментарии и история сохраняются в памяти текущего экрана; таймер миссии демонстрационный.

## Локальные данные

`demo.ts` создаёт 46 вымышленных записей и три проекта. `use-tasks-controller.ts` заменяет серверные операции изменениями в памяти. Редакторы и перенос сохраняют исходные сценарии. Позиции прокрутки также находятся в памяти, без browser storage.

Account сохраняет экран между вкладками. Перезагрузка, выход или смена аккаунта сбрасывают демонстрацию. API задач, БД и фоновых запросов задач нет. Общая сессия входа Brai используется как прежде. Панель агента показывает исходное состояние незапущенного агента; запуск модели не подключён. Шрифт и его OFL находятся в `apps/web/public/do` и включаются в production image.
