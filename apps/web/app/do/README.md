# Дела

Визуальные образцы взяты из Brai-Old, commit `4a93010c156f6c31c3955c39de08f8e2b8ef72c8`: `ActionRow` задаёт компактную геометрию `TaskRow` и `TaskContent`, а `ActivityDetailEditor` и `OperationDetailPanel` — ориентиры для редакторов и подробностей. Раздел сохраняет иерархию и поведение задачника `Q-Fox-Labs/Brai_september`, commit `64c26febe00d907c025fb44d3b39121536624636`. Для кнопок, полей и карточек используются общие компоненты Brai. Цвета следуют выбранной светлой или тёмной теме; миссии, квесты и цели сохраняют отдельные акценты. Интерфейс использует общий шрифт Geist и переключается в мобильный режим при ширине окна до 860 px.

## Взаимодействия

Миссия содержит квесты, квест — цели, цель — задачи. Каждый вид может находиться в корне. Кружки показывают состояния непосредственных детей. Выполненные и отменённые задачи закрывают прогресс. Активный блокер запрещает завершить зависимый элемент; ссылки открывают связанные записи.

Заголовок редактируется прямо в строке, а описание и результат — в подробностях. Курсор заголовка ставится в точку клика по тексту с помощью `detailOffsetAtPoint`; исходный September ставил его в конец. Enter делит заголовок и создаёт соседний черновик, Shift+Enter открывает описание, Cmd+Enter создаёт вложенный элемент подходящего вида, Escape отменяет изменение. Черновик сохраняется при потере фокуса.

Свободная область строки открывает подробности. Меню, вкладки, формы, раскрытие ветвей и обработчики переноса взяты из оригинала. Перенос меняет порядок соседей или родителя подходящего уровня. Зоны у контейнеров выносят запись в корень; перенос на проект меняет проект всей корневой ветви. Автопрокрутка использует исходные пороги и скорости: 72 px/s в пределах 64 px, 216 px/s в пределах 28 px. Завершение переноса останавливает её.

В строке показывается постоянный числовой ID; в подробностях — относительный номер `M/Q/G/A-ID` с позициями потомков. Поиск по ID раскрывает родителей. Проекты можно добавлять и переставлять. Комментарии и история сохраняются в памяти текущего экрана; таймер миссии демонстрационный.

## Локальные данные

`demo.ts` создаёт 46 вымышленных записей и три проекта. `use-tasks-controller.ts` заменяет серверные операции изменениями в памяти. Редакторы и перенос сохраняют исходные сценарии. Позиции прокрутки также находятся в памяти, без browser storage.

Account сохраняет экран между вкладками. Перезагрузка, выход или смена аккаунта сбрасывают демонстрацию. API задач, БД и фоновых запросов задач нет. Общая сессия входа Brai используется как прежде. Панель агента показывает исходное состояние незапущенного агента; запуск модели не подключён. Файлы Manrope и лицензия OFL остаются ассетами в `apps/web/public/do`; экран их больше не подключает.
