# Дела

Раздел `/do` переносит визуальный задачник Brai September в общую тёмную оболочку. Источник: `Q-Fox-Labs/Brai_september`, коммит `64c26febe00d907c025fb44d3b39121536624636`, компоненты `TaskRow`, `TaskContent`, `TasksView`, алгоритмы `model` и `use-task-drag`.

## Поведение

Миссия содержит квесты, квест — цели, цель — задачи. Каждый вид может существовать в корне. Зелёные, синие и жёлтые индикаторы обозначают контейнеры; серые — задачи. Кружки показывают состояние непосредственных детей. Выполненные и отменённые задачи закрывают прогресс; контейнер закрывается, когда закрыты все его дети. Активный блокер запрещает завершить зависимую задачу; ссылка открывает блокер.

Клик по индикатору контейнера раскрывает его. Название редактируется в строке; свободная область строки и кнопка справа открывают подробности. Доступны описание, результат, структура, связи, добавление и удаление дел. Кнопки «Выше», «Ниже» и «Вынести из родителя» позволяют менять порядок без перетаскивания.

Перенос за свободную область строки меняет порядок соседей либо помещает запись в контейнер подходящего уровня. Отдельные зоны сверху и снизу выносят её из родителя. Перенос на проект меняет проект всей корневой ветви. Номера `M/Q/G/A-ID` и позиции потомков пересчитываются после изменения дерева; постоянный ID сохраняется. Поиск по ID раскрывает родителей и показывает найденную запись.

У краёв прокручиваемой панели перенос включает прокрутку: 72 px/s в пределах 64 px и 216 px/s в пределах 28 px. Отпускание, отмена, уход из панели и скрытие экрана останавливают её. На узком экране проекты открываются отдельной панелью, подробности — нижней панелью.

## Данные и границы

`demo.ts` создаёт вымышленные проекты и записи. `model.ts` вычисляет порядок, статусы и нумерацию без React и внешних операций. Экран владеет изменениями; Account сохраняет посещённый экран между вкладками. Перезагрузка, выход или смена аккаунта сбрасывают демонстрацию. API задач, БД, browser storage и фоновых запросов задач нет. Вход использует общую существующую сессию Brai.

Синтетический задачник не запускает агента и таймер и не запрашивает серверные комментарии или историю.
