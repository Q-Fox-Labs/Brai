# Geist web fonts

The web root layout loads Geist Sans and Geist Mono with `next/font` from the pinned `geist@1.7.2` package. Next.js includes their font files with the application; visiting the site does not request fonts from an external service.

`GEIST-OFL.txt` is the license included with `geist@1.7.2`: SIL Open Font License, version 1.1, copyright 2023 Vercel in collaboration with basement.studio.
