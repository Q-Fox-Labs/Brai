# Работа с Brai

Перед работой прочитай [главный документ документации](docs/README.md). Затем следуй ссылкам к нужному разделу и компоненту.

Если рядом доступен проект Admin, дополнительно прочитай и соблюдай его `AGENTS.md`: он содержит правила разработки и эксплуатации нашей среды. Без Admin сведения о продукте доступны через документацию Brai.

При изменении зависимостей, конфигурации, каталогов или запуска компонентов одновременно сопровождай операторские плейбуки в соседнем Admin, если он доступен: клиентский `ansible/client/install.yml` и административный `ansible/install.yml`. Оба плейбука и общие роли хранятся только в Admin. Их клиентский состав соответствует принятому PROD; наличие кода в Git не включает компонент в продукт. Отдельный пользовательский установщик будет другой задачей.
