# Работа с Brai

Перед работой прочитай [главный документ документации](docs/README.md). Затем следуй ссылкам к нужному разделу и компоненту.

Если рядом доступен проект Admin, дополнительно прочитай и соблюдай его `AGENTS.md`: он содержит правила разработки и эксплуатации нашей среды. Без Admin сведения о продукте доступны через документацию Brai.

При изменении зависимостей, конфигурации, каталогов или запуска компонентов одновременно проверяй и обновляй [клиентскую установку](deploy/ansible/README.md). Её состав соответствует принятому PROD. DEV и административные дополнения принадлежат установщику Admin; наличие кода в Git не включает компонент в продукт. Сопровождение установки входит в ту же задачу.
